Why we built it

Plan mode nags. Auto mode is blind.

Agentic coding ships with two settings: answer every question yourself, or stop being asked at all. Neither is control.

Plan mode: you're the bottleneck

Every Edit and every Bash waits on a yes. You alt-tab through panes hunting for who asked what, and your flow dies on every switch.

Auto mode: you're out of the loop

So everyone flips to auto and hopes. The work speeds up, and you find out what the agent did to your repo after it already did it.

PcNotch: speed and veto

Every question from every agent lands in one place, the notch, and you answer in a click without leaving your editor. Risky commands arrive in red, flagged by deterministic hooks. Zero LLM calls, zero tokens, native Swift.

What it does

A control room the size of a notch

No dock icon, no windows to manage, no LLM calls of its own. It just watches, and taps you when it matters.

Live session list

Every session, ≤2h: real task titles, model chip, tokens & cost, and a status you can read at a glance: Thinking, Running tool, Compacting, Needs approval, Done.

Approvals in the notch

Permission requests pause and surface right in the island with Deny / Allow. Edit & Write requests render a red/green diff with +N −M before you decide.

The island opens itself

The moment an agent needs you, the notch glows orange and chimes. Answer it, and it folds back away. Calm the rest of the time.

Remote control

Stop a runaway session with one click, nudge a follow-up prompt straight into its pane, or answer Ask cards by tapping an option button.

One-click jump

Lands you in the exact Terminal.app / iTerm2 tab, or the precise tmux pane, running that session. No more alt-tab archaeology.

Shelf, quota & cost

Drop files on the island to park them, drag them out anywhere later. Pixel quota meters and a rolling cost odometer keep "$ today" honest.

Safety

Built to never surprise you

Deny wins, always

Approval contract is deny-first. Requests are risk-graded red/amber/green, so rm -rf never looks like ls.

Fails open, not stuck

Stuck requests fall back to the terminal after 45s; stale ones are swept after 15 min. Nothing blocks forever.

One-file kill switch

touch ~/.pcnotc/disabled and the hook exits instantly: every feature off, no restart needed.

Hooks, not vibes

Deterministic hooks grade every request before it runs. No model judgment, no tokens. Destructive commands show red in the notch before they can happen.

Localhost only

The optional streaming proxy binds 127.0.0.1, never logs auth headers, and is off unless you opt in.
