## Why

Plan mode nags — every Edit and Bash waits on a yes. Auto mode is blind — you find out what the agent did after it did it. PcNotch gives you both speed and veto: every question from every agent lands in the notch, one click answers it, and deterministic hooks flag destructive commands in red before they run. Zero LLM calls, zero tokens, native Swift.
